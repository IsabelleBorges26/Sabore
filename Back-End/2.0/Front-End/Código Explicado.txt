========================================================================
SABORÉ — DOCUMENTAÇÃO DE ANIMAÇÕES DO PROJETO
========================================================================

Este documento detalha e explica todas as animações implementadas no frontend do projeto SABORÉ (HTML, CSS e JavaScript), descrevendo seus propósitos de design, as regras CSS utilizadas e o comportamento interativo esperado.

O projeto utiliza micro-interações, transições suaves de estado (transition) e animações baseadas em quadros-chave (keyframes) para criar uma experiência de uso premium, viva e responsiva.

---

1. ANIMAÇÕES GERAIS E ESTRUTURAIS
========================================================================

1.1. Cursor Customizado Dinâmico (.custom-cursor)
------------------------------------------------------------------------
* Onde é usado: Em todas as telas da Dashboard (Home, Livros), na página de Login e na página de Cadastro.
* Como funciona: O cursor padrão do navegador é ocultado através do CSS (`cursor: none !important`). Um elemento <div> estilizado com a imagem do cursor ('cursor mouse.png') segue a posição do mouse via JavaScript.
* Comportamento e Transições:
  - Movimentação suave seguindo as coordenadas `clientX` e `clientY`.
  - Transição de escala no hover: Quando o mouse passa por cima de qualquer elemento interativo (links, botões, inputs, cards), o cursor aumenta de tamanho suavemente:
    - CSS: `transition: width 0.2s, height 0.2s;`
    - Estado Hover: A classe `.hover` altera a largura e altura de 48px para 60px.

1.2. Transição de Modais (.modal-overlay e .modal-card)
------------------------------------------------------------------------
* Onde é usado: Em todos os popups (Gerador IA, Criar Livro, Importar Vídeo, Upload de Foto, Notificações e Confirmação de PRO).
* Como funciona:
  - O container overlay escurece o fundo e desfoca os elementos traseiros com um filtro de glassmorphism:
    - CSS: `backdrop-filter: blur(15px); transition: opacity 0.4s ease;`
  - O card do modal entra com um efeito de subida (slide up) e escala:
    - CSS: `transform: translateY(20px); transition: transform 0.4s cubic-bezier(0.16, 1, 0.3, 1);`
  - Quando aberto (classe `.open` ativa):
    - CSS: `opacity: 1; transform: translateY(0);`

2. ANIMAÇÕES DA PÁGINA INICIAL (LANDING PAGE)
========================================================================

2.1. Animação de Flutuação Suave dos Elementos do Hero (Suco e Sobremesa)
------------------------------------------------------------------------
* Onde é usado: Na imagem do Suco (`suco.png`) e na imagem da Sobremesa (`sobremesa.png`) que ficam nas laterais do prato de comida principal na seção Hero.
* Como funciona:
  - As imagens possuem animações de translação e rotação cíclicas e independentes para dar uma sensação de profundidade e dinamismo tridimensional (efeito parallax/flutuante).
  - CSS keyframes (exemplo para o suco):
    ```css
    @keyframes floatJuice {
      0% { transform: translateY(0) rotate(0deg); }
      50% { transform: translateY(-12px) rotate(3deg); }
      100% { transform: translateY(0) rotate(0deg); }
    }
    ```
  - Isso faz com que as bebidas e doces pareçam flutuar no ar ao redor do prato principal.

2.2. Efeito de Revelação ao Rolar a Página (Reveal on Scroll)
------------------------------------------------------------------------
* Onde é usado: Títulos, textos e cards de seções da Landing Page.
* Como funciona: Elementos com as classes `.reveal`, `.reveal-right` ou `.reveal-left` iniciam com opacidade zero e levemente deslocados do seu ponto de origem. Ao atingirem a viewport do usuário (controlado por IntersectionObserver via JavaScript), ganham a classe `.active` que executa a animação de entrada com suavidade:
  - CSS: `transition: all 1s cubic-bezier(0.215, 0.61, 0.355, 1);`

3. ANIMAÇÕES DA DASHBOARD (HOME)
========================================================================

3.1. Pulsação do Ícone de Upgrade PRO (pulseIcon)
------------------------------------------------------------------------
* Onde é usado: No ícone de raio da caixa de promoção do plano PRO na barra lateral (sidebar).
* Como funciona: Cria uma pulsação infinita de escala e sombra brilhante ao redor do ícone para chamar a atenção do usuário de forma não intrusiva.
* CSS Keyframes:
  ```css
  @keyframes pulseIcon {
    0% { transform: scale(1); box-shadow: 0 0 0 0 rgba(240, 213, 182, 0.4); }
    70% { transform: scale(1.05); box-shadow: 0 0 0 8px rgba(240, 213, 182, 0); }
    100% { transform: scale(1); box-shadow: 0 0 0 0 rgba(240, 213, 182, 0); }
  }
  ```

3.2. Efeito Hover nos Cards de Atalho Rápido (.quick-action-card)
------------------------------------------------------------------------
* Onde é usado: Nos botões principais da parte superior da dashboard ("Gerar com IA", "Analisar Foto", "Importar").
* Como funciona: Ao passar o mouse, o card se move levemente para cima e aumenta o brilho da sua cor de destaque (coral ou bege) através de um pseudoelemento:
  - CSS: `transform: translateY(-4px); box-shadow: 0 12px 30px rgba(0, 0, 0, 0.2);`
  - Efeito luminoso de fundo: `opacity: 0.12` do gradiente no hover.

3.3. Efeito de Escala nos Livros de Receitas (.book-card-item)
------------------------------------------------------------------------
* Onde é usado: Na listagem horizontal de livros na home.
* Como funciona: Ao fazer hover no card, a pasta/capa do livro inclina e se eleva, o ícone interno rotaciona 5 graus e se expande, e a cor do card assume o tom do destaque correspondente:
  - CSS Card: `transform: translateY(-6px); background: var(--secondary-light);`
  - CSS Ícone Cover: `transform: scale(1.1) rotate(5deg); background: var(--light);`

3.4. Zoom nos Cards de Receitas Favoritas (.recipe-card)
------------------------------------------------------------------------
* Onde é usado: Grid de receitas favoritas na Home.
* Como funciona: A imagem da receita sofre um zoom interno suave enquanto o card se eleva ligeiramente, mantendo a borda arredondada impecável (graças ao `overflow: hidden`):
  - CSS Card: `transform: translateY(-4px); box-shadow: 0 10px 30px rgba(0, 0, 0, 0.25);`
  - CSS Imagem: `transform: scale(1.08); transition: transform 0.6s ease;`

3.5. Spinner de Carregamento da IA (loader-spinner)
------------------------------------------------------------------------
* Onde é usado: No modal do Chef IA culinário enquanto a receita está sendo formulada.
* Como funciona:
  - O círculo externo gira continuamente a 360 graus:
    - CSS: `animation: spin 1s linear infinite;`
  - O ícone do robô no centro pisca sutilmente mudando de opacidade para indicar processamento.

4. ANIMAÇÕES DA TELA DE LIVROS (MEUS LIVROS)
========================================================================

4.1. Seleção Ativa de Coleções (.book-card-item.selected)
------------------------------------------------------------------------
* Onde é usado: Na listagem de coleções na página "Meus Livros".
* Como funciona: Ao clicar em uma pasta de livro de receitas, o card correspondente ganha uma borda brilhante em tom coral (`--accent`) e uma sombra de projeção suave, além de mostrar um ícone de marcação (check) no canto inferior direito para indicar a seleção ativa.

4.2. Flutuação de Ícone no Painel Vazio (floatEmptyIcon)
------------------------------------------------------------------------
* Onde é usado: No painel direito de exibição de receitas quando nenhuma pasta de livro está selecionada.
* Como funciona: O ícone central de livro aberto realiza uma flutuação vertical cíclica de 8px e muda levemente de cor para motivar a ação do usuário de selecionar um livro na grade.
* CSS Keyframes:
  ```css
  @keyframes floatEmptyIcon {
    0%, 100% { transform: translateY(0); }
    50% { transform: translateY(-8px); color: var(--accent); }
  }
  ```

4.3. Hover nos Itens de Receita (.recipe-item-card)
------------------------------------------------------------------------
* Onde é usado: Na lista vertical de pratos salvos dentro de uma pasta ativa.
* Como funciona:
  - O card adquire um fundo fosco transparente suave: `background: rgba(242, 244, 243, 0.05);`
  - O botão de visualizar receita se expande ligeiramente.
  - O botão de exclusão de receita (ícone de lixeira) muda de opacidade (`opacity: 0.2` para `0.6` ou `1.0`), aparecendo apenas quando o mouse está sobre o card correspondente para manter a interface limpa e organizada.
