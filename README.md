## 📋 Visão Geral

O **SABORÉ** é uma plataforma de receitas pensada para reunir facilidade, organização e interação em um único ambiente. O projeto foi desenvolvido como Trabalho de Conclusão de Curso e une uma interface web e um aplicativo mobile para oferecer uma experiência prática ao usuário.

### ✨ Destaques rápidos

| ⚙️ | Funcionalidade |
|:------:|:--------------|
| 🔍 | Busca simples e intuitiva |
| ❤️ | Favoritar receitas favoritas |
| 👤 | Cadastro e acesso de usuários |
| 📝 | Publicação de receitas próprias |
| 🔗 | Compartilhamento fácil entre pessoas |

---

## 🎯 Objetivos do Projeto

- Criar uma plataforma de receitas visualmente clara e intuitiva
- Facilitar o acesso a diferentes tipos de receitas
- Valorizar a interação entre usuários e conteúdo colaborativo
- Aplicar conceitos de desenvolvimento web e mobile em um projeto completo
